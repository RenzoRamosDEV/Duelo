# Openspec Propose Command
When executing `/opsx-propose`, DO NOT load any planning skill (e.g. `writing-plans`, `brainstorming`).
The command provides its own complete planning workflow — follow it exactly as written.
This is precise: scoped to one command, scoped to planning skills only. It doesn't conflict with the mandatory-skill rule for other tasks because it's a specific override, not a blanket exception.
